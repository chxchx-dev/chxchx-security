# Technical references

Primary upstream references used for v0.1.0 design:

- Fedora Tor package: https://packages.fedoraproject.org/pkgs/tor/tor/
- Tor Project installation guidance: https://support.torproject.org/little-t-tor/getting-started/installing/
- torsocks manual: https://manpages.debian.org/unstable/torsocks/torsocks.1.en.html
- Tor stream isolation specification: https://spec.torproject.org/path-spec/stream-isolation.html
- NetworkManager nmcli settings: https://www.networkmanager.dev/docs/api/latest/nm-settings-nmcli.html

The project intentionally consumes these maintained components instead of copying or reimplementing their security-critical functionality.
